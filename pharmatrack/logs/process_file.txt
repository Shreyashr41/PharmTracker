DATA STRUCTURE

medicines.csv:
- medicine_id (string, unique)
- medicine_name (string)
- category (string)
- reorder_level (int, >= 0)

inventory.csv:
- batch_id (string, unique)
- medicine_id (string, FK to medicines)
- quantity (int, >= 0)
- purchase_price (float, > 0)
- selling_price (float, > 0)
- expiry_date (date, YYYY-MM-DD)
- supplier (string)

sales.csv:
- sale_id (string, unique)
- date (date, YYYY-MM-DD)
- batch_id (string, FK to inventory)
- quantity_sold (int, > 0)
- unit_price (float, > 0)

WORKFLOW COMMANDS

Setup Environment:
```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

Generate Data:
```bash
cd pharmatrack
python -c "from src.data import generate_sample_data; generate_sample_data(seed=42)"
```

Validate Data:
```bash
cd pharmatrack
python -c "
from src.data import DataLoader
loader = DataLoader()
med, inv, sales, reports = loader.load_and_validate()
for name, r in reports.items():
    print(f'{name}: {\"VALID\" if r.valid else \"INVALID\"}')
"
```

Run Tests:
```bash
cd pharmatrack
python -m pytest tests/test_smoke.py tests/test_phase1.py -v
```

Launch App:
```bash
cd pharmatrack
streamlit run app.py
```
